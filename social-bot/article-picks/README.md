# 読まれた記事をXへ自動紹介（Buffer Free）

未発生新聞の**実測された記事別の反応**を参考に、記事をX（Veripsa）へ自動予約します。**投稿済みの記事は再投稿しません。** 既存のオリジナル短文投稿と同じBuffer Freeチャンネル・同じGitHub Actionsを共有するので、新たなX API契約、別の課金や二重スケジュールはありません。

## 動き方

**現行スケジュール：毎日0:05・12:05頃（JST）に既存のX予約処理が記事候補を判定。** Buffer側に設定済みの7つの投稿時刻が実際の公開タイミングを決めます。短文実験の予約上限は9件、記事紹介を含むチャンネル全体の上限は10件。**予約枠の最後の1件を記事候補用に残す**ので、短文の予約数が増えても記事推薦が永久に後回しになりにくい構成です。


- 既存 `.github/workflows/x-original-experiments.yml` が先にオリジナル短文を上限9件まで補充し、最後の空き枠を読者の反応がある記事に利用します。どちらも同じBuffer Freeチャンネル・排他制御・予約履歴を利用します。
- 判定には `/api/engagement` の**匿名ブラウザ単位の累積**記事閲覧、いいね、共有、別の記事への移動をGETで使用。人間の実人数、PV、Xの表示回数、週間ランキングだとは主張しません。
- **公開12時間以上、21日以内の記事**が対象。閲覧ブラウザ8以上、さらにいいね/共有/次記事移動の観測があるか、閲覧ブラウザ12以上なら候補にします。閾値は品質・人気を証明する数字ではなく、少数標本での過剰投稿を防ぐ目安。
- 実際の反応数が不足、API異常、Bufferのキューが満杯なら投稿しません。閲覧0や欠損を勝手に「バズ」へ変換しません。短文投稿側は続きます。
- **直近の勢いも比較**：既存の `analytics/daily/` に同じ単位の実測スナップショット（記録から6〜72時間）があれば、前回記録から増えた閲覧ブラウザ・いいね・共有・回遊を計算し、増分が大きい記事を優先します。これは「当日PV」や「24時間の訪問人数」ではなく**2つの計測時点間の累積カウンター差分**。記事が計測後に公開された場合だけ基準を0とできます。
- スナップショットが古い・破損・欠落、もしくは新旧のカウンター定義や値が整合しない場合は、**差分を推測せず累計による従来の選び方へ戻す**。新規のAPI・スクレイピング・追加課金は行いません。
- **72時間に1本まで、1回に最大1本、Buffer内の予約合計最大10件（短文側は9件）**。短文の予約枠を維持しながら、条件を満たす記事を最後の空き枠へ最大1本だけ追加します。
- 本文は `【未発生新聞】` + 記事の見出し + **正規の当該記事URL**。「創作」「架空」「フィクション」の定型注記を毎回付けず、媒体の説明はリンク先の編集方針・記事ページに任せます。無関係なタグ・トレンド便乗・根拠のない「1位」「大人気」「バズ」を付けません。自動画像添付はしません。記事リンクのOGP画像は既存の公開画像を利用できます。

## 重複防止

`social-bot/article-picks/state.json` に**記事slugとBuffer受理IDを永続保存**。同じ記事は本文や見出しが変わっても再投稿しません。送信成功後にGitHubへの保存が失敗しても、次回、Bufferの `scheduled/sent` から同じ正規記事URL（クエリ付きも含む）を探して台帳を復元します。Xに**直接手動投稿した記事**や短縮URLはBufferのAPIで見えないため自動照合できません。そこまで含めて絶対重複なしとは約束できません。

現実の公開履歴、Buffer予約状態、実際のX上での公開、Xインプレッションは別々の事実です。「Bufferに予約した」はXへ公開済み・Xインプレッション獲得の証拠ではありません。

## 停止と確認

- **記事紹介だけ停止**：`social-bot/article-picks/config.json` の `"enabled": false` をmainへ反映。既存短文はそのまま運用。すでにBufferに入った予約は、必要ならBuffer画面でも取り消します。
- **全X自動予約を止める**：別途、既存の短文用 `social-bot/experiments/config.json` のスイッチもOFFにし、必要ならGitHub ActionsワークフローをDisable。
- **確認**：[共通のX投稿ワークフロー](https://github.com/RollNuts/mihassei-news/actions/workflows/x-original-experiments.yml)、記事紹介の `state.json`、Bufferの予約一覧を確認。アクセス数の水増し・自動いいね・フォローはしません。

追加費用は0円を維持。外部AI API、X有料API、Buffer有料プラン、GitHub追加有料機能は使用しません。
