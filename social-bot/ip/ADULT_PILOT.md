# ネジまち 大人向け漫画作画パイロット（非正史・非公開）

2026-11-03。**この試作は本編第7話ではなく、出稿対象でもない。** `social-bot/ip/adult_pilot.py` と `test_adult_pilot.py` のみで描画し、`social-bot/ip/previews/` に画像を作る。`posts.json`、`ledger.json`、`state.json`、Buffer、公式のキャラクター設定は編集しない。Xの品質停止を維持する。

## 何を試すのか

**『異常なし』**：大きな機械の騒音で眠れないネジが相談窓口の音声入力を使おうとする。機械の轟音で声が拾われず、巨大な相談件数表示は「0件」のまま。重要なのは「声が拾われない機械」の映像的オチであって、説明台詞で制度を批判することではない。

4つの異なる画面距離で試す。

1. 引き：配管と巨大機械に圧倒される小さな整備員、六番配管街の相談窓口。
2. 手元／接写：古びた音声入力装置と、案内するピトの片目。
3. 横からの寄り：ネジは声を出すが、工場の騒音に飲まれる。
4. 大ゴマ：街の巨大な相談件数表示「騒音相談：0件」。機械は止まっていない。

## 造形の条件

- **ネジ**：欠けた銅六角・一本の右ネジ・紺色の古い作業着・退色した黄マフラー。金属の擦れと非対称性で記号性を出す。赤い頬や大きなガラスの瞳は禁止。
- **ピト**：古い横長の一つ目端末。浮遊輪と微細な傷で非人間的な愛嬌を作る。
- **モク**：角のある不定形の薄紫蒸気と橙の手袋。キャラ原型シートのみ登場。幼児的な動物化をしない。
- 背景は装置、錆、石、暗い空間、鈍い灯り。線はわずかに揺らぐが、線のざらつき**だけで**漫画の魅力が出ると考えない。

## 警戒点と判断

- これはPython/Pillowだけで再現可能な**作画研究**であり、人の画力や生成モデルの表現力を自動再現できるわけではない。
- 顔が暗すぎて視線を追えない、配管で主役が埋もれる、画面を小さくすると文字が読めない、笑いが伝わらない、または既存作品の印象を連想する場合は**不採用**。
- 使い回しの背景・静止した立ち絵を繰り返していないか、漫画を頭から読んで確認する。自動テストは画像が壊れていないこと等を確かめるだけで、笑えることを証明しない。
- 高品質の正式な画集やぬいぐるみデザインとしての完成承認とは区別する。
- **出稿再開はユーザーの目視評価と明示的承認が必要**。`publication_quality_gate.json` はfalse、`episode_reviews.json` は承認0件のままにする。

## 費用・安全

無料のGitHub Actionsランナー・Pillow・Noto CJKだけ。OpenAI API、画像生成API、X有料API、外部の従量課金サービスは使わない。`previews/` は出稿対象の `social-bot/assets/` とは別。自動生成の新しい画像はファイル名・容量を固定し、画像が変わっても正史を変更しない。

## 2026-11-04 実画像比較と単一点の試作（非正史）

既刊の第1話・不採用の第6話のPNGと、現在の `adult_city_quiet_pilot.png` / `adult_cast_sheet.png` を比較した。従来作の正面リアクション反復、赤頬っぽい擦り線、糸吊りを連想させる第6話の構図に対し、試作は引き・手元・横顔・遠景の変化と最後の「受理件数 0」が明確になった。一方、第3コマのネジは「うるさいんです！」と言っているのに、実際の横顔の口が閉じた短い線で、行動が読み取りづらかった。

今回は**表情のみ**修正し、横顔で大声を出す場合に限り口を少し開く。新規の話数・設定・ルールは増やさず、以前のPNGも変更しない。検証はプレビューの生成テストと**スマホ幅約360pxでの人間の見比べ**を必要とする。コード試験に成功しても絵の出来や笑いの最終判定にはならない。Pillowでは自然な筆圧、重量感のある全身演技、漫画家が描く躍動感はまだ再現できないため、承認済みとは扱わない。
