# ネジまち｜大人向け漫画IPの出稿審査と再開手順

最終更新：2026-11-03。**Xの新規予約は現在停止**。新作制作や構図研究と、公開・予約の許可は別々に管理する。

## この変更の理由

- キャラに幼児向けの赤ほっぺ・玩具的な丸みが出たことと、第6話の糸で吊られた巨大な影が既存ヒーローに似て見えることを指摘された。
- 手描き風ノイズだけでは漫画が面白くならない。正面立ち絵を繰り返さず、カメラ・間・動作・背景を**話のオチに必要なもの**だけで組み立てる。
- **GitHubへ原稿が存在する＝公開承認済み、ではない**。特に第6話「おおきな影」は制作履歴として保持するが、公開不許可とする。

## 二重ゲート（無料）

1. `publication_quality_gate.json` の `new_reservations_enabled` が明示的に `true`。
2. `episode_reviews.json` の `approved` に **オーナーが目視承認したその話の** `post_sha256` / `image_sha256` / `reviewed_at_jst` / `approved_by: owner` / `age_target: adult` が存在すること。
3. `rejected` にある話は**承認ファイルを後から書き換えても、そのまま投稿しない**。いったん見直し対象として新しい脚本・別IDで作り直し、正史と投稿順の再設計が必要。
4. 過去話のBuffer上での状態が **sentまたはscheduled** と確定できないとき、後ろの話を勝手に投稿してよいとは判断しない（例：第1・2話は現在Bufferの下書きへ退避済み）。
5. `ip/history_guard.py` と `ip/art_history_guard.py` は過去の原稿と画像を不変として保護する。

これらの検査はローカルのPython標準ライブラリ+Pillowのみ。新たな有料APIや新しい課金枠を設けない。

## 再開するために必要な制作物

**まず原型3体の統一された立ち絵・側面・身振りと、見開きではない縦漫画1本。**
正史の特徴を残す（銅の欠けた六角頭・旧型一つ目端末・角のある薄紫の蒸気体）。
絵はガタガタ線や濃いパステルではなく、煤、褪せた銅、鈍い藍、湿った石畳、朽ちた機器など硬質な街との対比で成立させる。

- 1コマ目は**街の大きさと、何をしようとしているかが一瞬でわかる**引き。
- 2コマ目は目や小道具の寄り。セリフに頼りすぎず、狙い/失敗の原因を見せる。
- 中盤は反転した視点・手元・背中など、場面に合った別構図。3コマ連続の正面立ち絵は禁止。
- オチは世界観の説明や説教でなく、**人物の行動か、物の見た目が変わる**こと。読み終わって少し皮肉が残る程度。
- NG：丸い子猫・ハリネズミ・つぶらな大きい目・赤い頬・幼児玩具、スーパーヒーロー衣装や糸で吊るポーズ、既存作品の特徴的な構図/語尾/ネタ。

**いまは試作だけ。** メインブランチに作画の実験や新しいルールを追加しても `approved` を自動作成したり、品質ゲートをONにすることは禁止。

## オーナーの承認フロー

作品が完成したら、絵・本文・文字の可読性をスマホ幅で直接確認する。承認できた回の現在のJSONとPNGからSHA256を計算する（生成ツールは承認文面の**下書きだけ**を出力し、承認印は押さない）。

ただし過去1・2話はBufferで下書きへ退避済みのため、**第3話だけを先に自動公開してはいけない**。再掲載、リブート、別シリーズとして開始などの編集方針が決まるまで出稿しない。これを破るために過去の `state.json` を消したり、偽の送信記録を書いてはならない。

## 実務上の優先順位

1. 独自キャラのデザインを大人向けに修正（目視の評価が必要）。
2. 30秒で内容が理解できる試作漫画を1本用意し、スマホサイズで読めるか確認。
3. 同じ顔・背景の反復を排除し、手描き質感の品質を見直す。
4. 原作類似の危険箇所と正史・台本の整合を点検。
5. 読者が納得するまで新規予約停止を維持。改善内容は次の試作に反映する。

## 検証の限界

SHA256や文字数、投稿順は機械検査できる。しかし**面白さ・手描きの魅力・既存作品との類似性の最終判断は自動化できない**。自動検査の成功だけで承認しない。
