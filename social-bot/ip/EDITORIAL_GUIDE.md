# ネジまち｜大人向けキャラクターIPの最優先アートディレクション（2026-11-03）

> **ユーザーの修正指示：子ども向けのキャラクターではない。** 「ゆるい」を「幼児向け・赤ほっぺ・ぷにぷにのマスコット」と解釈しない。本節は下記の過去のラフ案・「かわいくする」指示より優先する。今後の編集と自動制作は必ずここを先に読む。

## 想定読者と作品の質感

- **大人が面白がる機械都市の風刺漫画**。笑いは制度と日常のズレ・乾いた一言・気まずい間・弱いけど賢い選択から生む。子ども向けの説明・教訓・がんばろう演説を入れない。
- 愛嬌は誇張した乳児体形や赤い頬ではなく、無骨で少し不格好な顔と動き、表情の変化、関係性から生む。
- 街は**大きく硬質で少し退廃的**。錆びた銅管、煤、湿った石畳、昔の案内看板、低く灯るネオンと作業灯など。機械都市は写実的に重みを持たせ、住人は簡素な造形との対比で見せる。
- カラーは鈍い銅、くすんだ藍、薄紫、灰青、汚れた紙の白、控えめな灯り色。幼稚園のポスターのような高彩度パステル、虹色、ツヤツヤの玩具的な塗りを避ける。
- 線は鉛筆・墨・古い版画のような**意図のある手描き線**。表面にノイズを重ねただけでは不合格。形の崩れや筆圧の変化、光と影、汚れと素材感をコマごとに設計する。
- **既存の6話・既存キャラクターの正史を勝手に変更しない。** 新規のデザイン試作は正式な設定更新の前段階として扱う。品質ゲートが停止中はBuffer投稿を再開しない。

## 独自の人物造形：子どもっぽくしない

- ネジ：欠けのある銅色の六角頭・右の小ネジ・使い込んだ紺の作業着・退色した黄色の短いマフラー。目は必要最小限。小さくても工業部品の手触り・重心がある。表情は顔パーツより立ち方・視線・手つきで出す。
- ピト：横長で古い淡青の一つ目端末。無機質な表示・筐体の小さな傷・わずかな傾きで個性を出す。丸いペットロボットや幼児玩具にはしない。
- モク：薄紫の角ばった蒸気／煤の塊、橙色の作業手袋、小さな靴。柔らかい存在だが、顔を丸くしすぎず、輪郭が揺れる・手袋をいじる・動きをためらう仕草で愛着を作る。動物（猫・ハリネズミ等）へは置換しない。

**禁止の近道**：赤ほっぺ、きらきら大きな目、ぬいぐるみ風の短すぎる手足、過度な丸顔、無邪気さだけの台詞、ハート・星・虹で装飾、キャラクターを見下す笑い、他作品の象徴的な衣装・顔・演出を借りること。

## 漫画のネームとオチ

1. 大きな背景に対して人物のちっぽけさを見せる「引き」、手つきと表情の「寄り」、行動をはっきり見せる「横・背面・俯瞰」を、話の意味に応じて使う。全コマ同じ正面顔は禁止。
2. ギャグは「壮大な都市のくだらない欠陥」「情けない努力と小さな成果」「まじめなキャラの的外れな結論」などから。世界の説明や人生の教訓をオチにしない。
3. ネジ・ピト・モクの感情は控えめに描き、乾いた会話と間を活用する。笑いを説明しない。
4. 独創性確認はキャラのシルエット・配色・物語・構図を別々に行う。既存の原作漫画の画像やキャラをモデルに学習・合成・トレースして使わない。
5. **品質評価**：成人読者が見て「子ども向けの知育漫画」「ほっこり教訓漫画」に感じるなら作り直す。キャラクターへの愛着と、世界への皮肉が両立していること。

## 2026-11-03 重大な視覚品質レビュー（公開前の停止条件）

**第6話「おおきな影」の試作画は不採用。** 糸で吊った影の演出が既存のヒーロー作品に似て見え、手描きの愛嬌も不十分と指摘された。画像に同じ雰囲気のヒーロー的なシルエットや蜘蛛の糸、マスク・コスチューム、宙づりポーズ、誇張した戦闘構図を入れない。意図せぬ類似であっても掲載しない。既存のIPの固有造形・表情を持ち込まない。

**漫画としての改善を優先する。** 単に線を細かく揺らしただけのプログラム絵は手描き感とは言えない。キャラの見た目だけでなく、左右非対称の手足が動く仕草、目線・間・失敗時の体のゆがみ、道具との接触、手描き線の強弱や抑揚を作る。幼児向けの赤い頬・つやつやした大きな目・過度な丸みを安易に足さない。

- ネジ：欠けた銅色の六角頭・小さな右ネジ・黄色のマフラーは正史として残す。ただし六角頭の欠け・金属の擦り傷・作業服の重量感を生かし、目と手先の小さな動きで感情が見える比率を試す。子ども風の頭身や過度な丸顔に寄せない。
- ピト：一つ目の淡青の横長端末と浮遊輪を残す。まばたきに相当する画面の変化や傾きで、悪役にせず表情を見せる。
- モク：薄紫の凸凹した蒸気形と橙の手袋・小靴を残す。片手の握り方や輪郭のへこみで嬉しさ・困り顔・恥ずかしさを見せる。別種の猫・ハリネズミ等には置換しない。
- 画面の基準：48px縮小でも区別できる独自シルエット、背景よりキャラの顔が先に見える、各コマの大きさに変化がある、同じ正面立ちの連続を避ける。
- **新規予約は、`publication_quality_gate.json` がfalseの間停止。** 日次制作は新しい連載話数を勝手に積み増さず、作画の改善・サンプルと品質評価を優先。既に公開・予約した画像も自動的には改変しない。再開には独自のキャラデザインと、スマホサイズで読める漫画の確認が必要。

# ネジまち 漫画演出の編集基準 v1.1（2026-11-03）

## なぜ見直すか

「難しい話を読ませる」のではなく、**一目で誰が何を望み、何が起こり、どう感じたか**を読者が理解できる漫画にする。原作漫画の観察に基づく一般的なストーリーテリング原則を学ぶが、特定作品の絵柄・キャラクター・口癖・固有エピソード・画面の組み立てを模倣しない。

## ネジまち固有の差別化

- **世界**：天井灯のある巨大な機械都市「トルマ市・六番配管街」。小型の住人が巨大な都市設備の隙間に暮らす。
- **主役**：欠けた六角頭と黄色いマフラーのネジ。彼の視点は、仕事論や抽象的な社会批評ではなく「自分の目の前の困りごとを何とかする」。
- **相棒**：画面に一つ目の浮遊機械ピト。規則を作るのではなく案内する。悪役として貶めない。
- **友人**：紫の蒸気生物モク。失敗や喜びを体の形・手袋・動きで見せる。
- **読後感**：機械都市の大きさに対して住人の願いは小さい。笑いの中でキャラを守りたくなる気持ちを残す。
- **想像を残す**：中央塔の制定者、天井の向こうは未解決。雰囲気づくりのためにも説明しすぎない。正史は `canon.json` と `ledger.json`。

## 「5秒でわかる」新規エピソードの制作フロー

1. **読者が初見でもわかる**：1コマ目に主体・今したいこと・物を見せる。世界観用語だけで始めない。
2. **一つの出来事に絞る**：各話の中心は「○○したい → ○○が起きる → ○○する」で一文にできること。設定解説は主役にしない。
3. **一コマ一動作**：各コマに「見える行動」を指定。人物が四コマとも同じ正面立ちなら構成し直す。
4. **文字より表情**：セリフは短く、無言のコマを使える。無言は「意味のない空白」ではなく、表情か小道具で意味が分かる場面にする。
5. **最後は変化で終わる**：読者が図だけ見ても、何が変わったのか大体分かる。最後の一文で主題を説明しない。
6. **感情の波を作る**：ネジやモクの嬉しさ・恥ずかしさ・気まずさ・小さな助け合いを明確に。制度への皮肉ばかり連発しない。
7. **2〜6コマ自由**：場面の呼吸で枚数を決める。2コマなら対比、3コマなら意外な解決、5〜6コマなら時間や感情の変化。4コマ固定禁止。
8. **各回は独立**：次回の連載伏線は一要素だけ。過去話を読まなくても、当該話の小事件の意味がわかる。
9. **オリジナル性**：機械都市ならではの小道具・空間・社会法則・キャラクターの選択が必要。既存IPの具体的な話・見た目・語尾・笑いどころを「借りない」。
10. **スマホの実寸で見直す**：文字切れ、背景との同化、4コマ以上で人物が小さすぎないか。セリフを消してもオチが伝わるか。

## 描画スクリプトの新しい任意フィールド（第4話以降）

- `shot`: `wide`（街の大きさを見せる）、`medium`（通常）、`close`（表情を強く見せる）。過去作品はデフォルトのまま維持。
- `silent`: `true` の場合 `line: ""` としてセリフの帯を描かない。ただし `mood` は `plain` 以外、もしくは意味のある `prop` を設定する。
- `prop`: `bolt`（部品）、`ticket`（札）、`lamp`（天井灯の模型）、`cup`（飲み物）、`none`（なし）。世界観固有の物で視覚的な説明を補う。
- `action`: 何をしているかを短い日本語で説明する*編集用指示*。画像に文字表示しない。第4話から各コマに必須。絵の実装で動作を示せるか人間が確認。
- `episode_core`: 各話の「○○したい → ○○に邪魔される → ○○する」の一文を編集用に保存。第4話から必須（画像には表示しない）。

### 短く、絵で伝えるための追加ルール

- **第4話から** 1つのコマのセリフを合計55文字以下、1行28文字以下にする。長さを満たしても説明台詞が多ければ直す。
- 3コマ以上ならカメラショットを最低2種類使い、絵の変化を出す（構図反復が意図的に必要な場合は編集判断を優先）。
- 各回の「誰が何をしたい → 小さな事件 → 具体的な変化」は `episode_core` に一文で残す。抽象的な社会論に置き換えない。
- `visual: "glove-cover"` は、**ネジまち固有**の工業用の大きな手袋が小さなネジを隠してしまう画面表現。使う前に絵で理解できるか確認する。汎用の無意味な効果は追加しない。
- すでにGitHubに統合した旧画像は**再描画しない**。作画改善は次話から適用し、過去の画像を改変するPRは履歴検証で止める。
- 無言コマは説明的なテキストを削るための選択肢。必要ないなら無理に入れない。

### 改善が必要な既存の3話（既出は改稿しない）

- 第1話「朝の配給」：規則の面白さが中心でキャラの感情が弱い。次からは「ネジが本当に何をしたかったか」をコマに描く。
- 第2話「青空の品質」：青い照明の話なのに、絵でその色の違いが伝わりにくい。重要な変化は小道具・背景を動かして見せる。
- 第3話「親切の申請」：親切は伝わるが、最後の説明台詞が勝っている。次からは、ネジの行動とモクの表情でオチの半分以上を見せる。

**同じ規則ネタの三連続を避けるため、次回は機械都市の日常の小事件・視覚的な失敗・いたわりを優先する。**

## 週次レビュー

日次の「ネジまち 漫画連載・整合性保守」タスクでは、原稿の5秒テストと正史検証を両方実施。定期改善タスクでは、公開済み話を直すのではなく*次に追加する話の作り*を変える。

## 2026-11-03 制作改定：コマと手描き線を先に設計する

実物の第1〜5話を確認したところ、**全コマが同じ背景と正面立ち絵、平坦な線、台詞帯による解説**に偏っていた。漫画として面白くするには、セリフ削減だけでは足りない。

【無料の手描き風試験制作】
- `social-bot/ip/ink_storyboard.py` が第6話『おおきな影』の画面を構成。Pillow、固定seedの鉛筆風の揺らぎ、紙繊維粒子、ハッチング、セリフの吹き出しのみを使用（従量AI画像APIなし）。
- **第1コマは引き**で機械都市と小さなネジを見せ、**第2コマは巨大な影のあおり**、**第3コマは恐がる顔の寄り**、**最終コマを大きく**してモクの正体を見せる。
- 日本式の右→左、上→下で読む2段目を含む。絵の中で誰が何を見ているか、直前のコマとのつながりを明確にする。
- 影の正体は街灯の光による普通の投影。モクの新しい超能力や巨大化は**正史へ追加しない**。
- キャラの欠けた六角頭・黄色いマフラー、モクの蒸気型と手袋は維持し、他作品のデザインを模倣しない。

【今後の新作の品質ゲート】
1. **ネーム先行**：各話の4つの大きな感情・行動の変化を決め、カメラ位置（引き/寄り/俯瞰/あおり/手元/背面）・何を隠し何を見せるかを事前に定義。コマ数は2〜6から選ぶ。
2. **絵で伝える**：同じ人物の正面立ち絵を続けない。コマ間で最低2種類の距離/角度、1種類の明確な体の動きを使う。重要なボケは台詞ではなく**見えているもの**に置く。
3. **手描き感はシステムで再現**：決定的なseedで紙目、細い複線、軽い不均一な輪郭と鉛筆線を使う。ただし単純に線をブレさせただけで満足しない。
4. **新作は固有の見せ場を持つ**：同じ背景・表情・構図をコピーせず、話に必要なカメラや特殊な小道具をローカルPillowで追加。第6話以降は `art_style: "handink-v1"` と `ink_scene` を設定し、独自の描画処理がない新話は自動検証で止める。画像を作れない話は無理に投稿しない。
5. **正史と画稿は追記のみ**：`ip/history_guard.py`・`ip/art_history_guard.py` が原稿と過去画像の改変を禁止。既に予約したBuffer投稿も書き換えない。
6. **面白さの検証は別**：線の乱れやコマ数は自動テストできるが、読者が笑えるか、画面が魅力的かは機械だけで保証しない。週次改善会議では少なくとも実画像を1話確認し、次話の演出へ反映する。
