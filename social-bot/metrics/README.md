# Xインプレッション優先の運用（2026-11-03）

## 最重要KPI

**投稿の表示回数（X impressions）を最優先**とする。世界観の細かさ、記事・漫画の本数、GitHubのコミット数は成果ではない。Xの利用規約と創作の独自性を守りつつ、継続的に見てもらえる面白い投稿を探す。

補助指標はリポスト、返信、いいね、プロフィールへのアクセス、フォロワー増加。インプだけを水増しする連投・釣り・重複・トレンドへの自動便乗は禁止する。

**現在のX投稿停止を継続**。 `social-bot/ip/publication_quality_gate.json` がfalseの間は画像・テキストを問わずXへ自動予約しない。未承認の漫画を投稿するために停止条件を迂回しない。

## 最初に検証する形式

| 系統 | 役割 | 最初に見る点 |
|---|---|---|
| `surreal_text` | 「幽霊の市場価値」のようなシュールな一文・二文の単発ネタ | 説明なしで意味が分かり、最後の一行が予想を裏切るか |
| `nejimachi_comic` | オリジナル機械都市・大人向けマンガ | スマホで絵だけでも状況とオチが分かるか、原型が覚えられるか |
| `character_moment` | ネジ・ピト・モクの短い日常と関係性 | 既存IPと違う、乾いた一言や気まずい間があるか |

単発テキストの成果が良ければ、無理に4コマを優先せずテキストを増やす。漫画が良ければ漫画に寄せる。「キャラビジネスとして将来有望」と「現在インプを獲得する」は分けて考える。

## 数字の取り方（追加費用0円）

- Xの各投稿のインサイトに表示される**実測のインプレッション**を使う。無料アカウントでは投稿別の基本統計が見られる場合があるが、管理画面の一括取得はプランで異なる。
- Buffer公式案内では無料Insightの一般的な機能がある一方、**Xの無料プランのSent投稿別データは取得できない**との制限も明記されている。よってBufferから自動で全投稿の表示回数を取れると決めつけない。
- Xまたは連携済み機能から信頼できる実測値を取得できない場合、 `records.json` にデータを追加せず「未取得」とする。**0インプと未取得は別**。
- APIの追加従量課金、有料X Premium、有料Buffer、スクレイピングによる規約回避は行わない。追加費用0円を堅持。

### ハッシュタグ実験の実測値を照合する場合

同じ投稿形式の中で「タグなし／関連タグ1個」を比較する。Xインサイトで実測表示回数が分かった投稿に限り、元の記録へ任意の `"experiment_id": "xexp-ufo-ticket"` を追加する。必須の `post_id` は**Xの実投稿ID**のまま保持し、Buffer IDとは混同しない。元の投稿のタグ有無は `social-bot/experiments/posts.json` に保存している。

`social-bot/experiments/review.py` が `experiment_id` を照合し、同一形式・24時間後の実測インプの中央値で比較する。各群5本未満は効果判定をしない。正規に取得できないインプは未取得（ゼロ扱い禁止）。冒頭・ネタの内容・時間帯が異なるため、差が出てもタグによる因果効果とは断定しない。

### 記録する1件の形式（実績が出た時のみ）

~~~json
{
  "post_id": "x-post-unique-id",
  "format": "surreal_text",
  "window_hours": 24,
  "captured_at_jst": "2026-11-04T21:00:00+09:00",
  "metric_source": "x_post_insights",
  "impressions": 150,
  "likes": 3,
  "reposts": 1,
  "replies": 0
}
~~~

**これは入力フォーマット例であり、実際のXの成果ではない**。 `records.json` は現在空。投稿ごとに24時間後、可能なら72時間後の数値を記録する。実数がなければ記録しない。過去投稿は複数時点の数字がある場合、同じ投稿・同じ測定窓の最新の報告を採用する。

`python social-bot/metrics/report.py` は、投稿形式ごとにサンプル数、中央値・合計・最大表示回数を出す。数が3本未満の形式は参考値と表示し、優劣を断定しない。合計だけの比較は、投稿本数が異なると誤解を生むため中央値も使う。

## 改善サイクル

1. **日次**：新しい作品アイデアは未公開の試作として検討。初見で理解できるか・オチはあるか・既出投稿と重複しないかを見る。品質停止中は投稿や正史に追加しない。
2. **週次**：実測可能な場合のみ、24h/72h表示回数の中央値を形式ごとに比較。タイトル・導入・コマ数・オチ・投稿時刻のうち**1つの変数**を次の試作で変える。
3. **3本以上の比較**：傾向を仮説として記録する。投稿時刻やフォロワー数などの交絡があるため、因果関係を決めつけない。
4. **品質の原則**：インプが上がっても、盗用・似すぎたキャラ・架空の事実を現実のニュースに装うこと・大量投稿はしない。
5. **再開条件**：承認を要する漫画は `episode_reviews.json` で承認し、`publication_quality_gate.json` をオーナーの指示なくtrueにしない。初回配信順と下書きへの退避歴も調整してから再開。
