# 次の9枠へ引き継ぐ編集品質メモ

- **JST更新日：** 2026-11-04
- **次の重点1つ：** ホットニュースは大きさより「説明コスト」で選ぶ。候補ごとに「現実の事実／観察した矛盾／未発生の展開」を各1文で言えない題材は、本文で説明を足して救わず別候補へ替える。
- **具体的な問題例1つ：** 元ニュースの制度名・人物関係・前記事を説明しないとオチが分からない案は、ホットでも弱い。良例の倍速視聴記事は「時間を節約したい→内容を見失う→解説を3時間見る」が記事単体で追え、元報道を知らなくても可笑しさが成立している。
- **次に避けること：** 「この件」「これを受け」「例の〜」など文脈依存の書き出し、固有名詞の知識を前提にした見出し、前提説明が本文の笑いより長い企画。弱い案を専門語の補足、別制度、別人物、二度目の逆転で救わない。ホットさだけで採用しない。
- **公開前の5点：** ①見出しだけで対象・状況・可笑しさが分かり、元ニュースや前記事を見ている前提になっていない ②冒頭2文で人物・出来事・原因が分かり、ホット題材は「現実の事実／観察した矛盾／未発生の展開」が各1文で成立する ③元の具体的な矛盾を一つの前提で誇張し、読者が自分の職場や生活に重ねられる ④本文に見出しを繰り返さず、その話ならではの行動・結果・一言の笑いがある ⑤直近と笑い方が違い、「これは何の話か」を80〜120字で追加説明なしに言い直せる。
