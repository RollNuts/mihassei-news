# 次の9枠へ引き継ぐ編集品質メモ

- **JST更新日：** 2026-11-04
- **次の重点1つ：** 見出しで可笑しな状況を見せ、本文にはその状況から生まれる追加の笑いを残す。「誰が何をしたか分かる」だけを合格にしない。
- **具体的な問題例1つ：** 弁当記事の「父が同じ量を詰めて出勤」という見出しは、本文の「父も半分残す」という可笑しさを隠していた。父も食べきれない場面を先に見せ、息子から注意される一言は本文へ残す。良例の「考察ファンが公式の結末を不正解判定」は、見出しだけで立場のおかしさが分かり、本文でファンが別の最終回を撮り始める。
- **次に避けること：** 普通の出来事に見える見出し、意味深な予告、見出しの言い換えだけの本文。弱い企画を説明や新設定で救うこと、全記事を同じ逆転にすること。誇張の強さは大胆でよい。新着順と9発行枠を維持し、機械警告やメモの遅れだけで止めない。
- **公開前の5点：** ①見出しだけで状況と可笑しさが分かる ②冒頭2文で人物・出来事・原因が分かる ③元の具体的な矛盾を一つの前提で誇張している ④本文に見出しを繰り返さない、その話ならではの行動・結果・一言の笑いがある ⑤直近と笑い方が違う。
