# 未発生新聞｜連載の編集方針（競合・読者調査から）

2026-11-03 時点の公開調査を参照した編集判断。**この調査は当サイトの実際の流入・好みを示すものではない**。各話の文章・安全性・公開の確認を優先し、管理画面や読者ツールの追加は原則しない。

## 参照した市場の状況
- インプレス総合研究所『電子書籍ビジネス調査報告書2026』: ウェブ小説の利用率16.5%（調査対象のモバイル利用者）。無料電子書籍のみ利用28.5%。数字は出版全体の傾向で、未発生新聞の潜在市場規模ではない。https://research.impress.co.jp/report/list/ebook/502499
- カクヨムのミステリーランキング: 多数の長編・連作短編が更新され、読者はあらすじ・話数・第1話の入口から作品を比較できる。ランキング上位だから特定の表現が有効という因果は主張しない。https://kakuyomu.jp/rankings/mystery/yearly?work_variation=all
- 楽天証券『行動ファイナンス研究レポート2026』: 回答者26,534人の情報源では自己判断35.4%、ブログ・動画等の無料情報24.1%。回答者属性は偏りがあるため、投資家全体の代表値や当サイトの読者像としない。https://www.rakuten-sec.co.jp/web/learn/report/2026/survey/
- 株探には適時開示・決算速報・個別銘柄ページなどの大規模な提供機能がある。速報で模倣競争せず、予想条件の事前固定と結果検証で差別化する。https://info.kabutan.jp/about/

## 未発生事件簿：つまらないなら発行しない

**現行の第1話を読んだ編集上の反省：**「翌日付の死亡届」「消された受付番号」「本人の筆跡」という着想には可能性がある一方、書類の説明に比べて登場人物の具体的な行動・葛藤が薄い。終盤も通話の途切れで引くだけになっており、同型を繰り返すと、伏線の多さだけが残って物語が進まない。次回からここを改善する。公開済み第1話自体は履歴保護のため無言で改稿しない。

- **原稿作成前に筋を決める。** 今回、読者の理解がどう変わり、誰が何を失いかけ、登場人物がどんな取り返しのつかない選択をするかを考える。犯人当てゲームより人間の切実さと異変を優先する。嘘、隠し事、見栄、恐れ、守りたい相手などの動機は抽象語で説明せず行動に現す。
- **各話に読後の変化を残す。** 新しい謎を足すだけでは不十分。前の疑問に進展・小さな答え・意外な反転を与え、人物関係か事態が変わる。何も起きない説明回を作らない。驚きは公平な手掛かりから逆算し、解決前の情報の出し惜しみで引っ張らない。
- **不採用になりやすい手癖を避ける。** 書類や時刻の羅列、捜査官が仮説を解説する長台詞、事件ではなく登場人物が頭の中で考えるだけの場面、急な電話・新しい声・意味深な一言だけで終わる回、専門語や設定の後出し、全員が同じ口調で話す会話、毎回同じ章立て。章数・字数を一律固定しない。
- **説明より場面。** 冒頭に独特の光景、対立、ためらい、失敗などを置く。誰が何を望んでいるか、危険を冒してまでその選択をする理由、結果として何を失うかを読者が感じられるようにする。被害予告を受けた人物を単なる謎解きの駒にしない。
- **公開前に最低1回、大きく改稿する。** 自分で反証するように再読。「この回を飛ばしても筋が変わらない」「読後に何も分からない」「同じ電話切断や不穏な余韻だけ」「答えが作者の新設定にしかない」なら構成から再執筆。自動採点やチェック項目を埋めるだけで合格にしない。再執筆しても弱ければその回の発行は見送る。対象をずらしてでも毎回出す方針は**架空ニュースの毎日発行に限定**し、小説には適用しない。
- **初めての人は第1話から。** 既読者には続きから読む導線を用意。読者メモ・強制クイズ・新たな会員機能は追加しない。内部の `clues` と `reader_prompt` は公平性点検に使い、記事末尾の振り返りは必要な人だけ開く。
- **既刊の全話を読む。** 人物・日時・筆跡・受付番号・旧館三階・手掛かり・知っている人物が誰かを照合。第1話の違和感を「実は未来が分かっていた」等の唐突な万能設定だけで説明しない。解決は伏線と人物の選択に結び付ける。既公開話を後出しで書き換えない。

## 未発生事件簿：具体的な物語づくり

文芸的な参考軸は伊坂幸太郎作品の**会話に性格が出る人物配置・別々の行動が後でつながる構成**と、東野圭吾作品の**検証できるトリック・犯行の因果・謎を解く人物自身の葛藤**。作家の文体・印象的な台詞・既存作品の仕掛け・登場人物は模倣しない。言葉だけ「伊坂風」「東野風」と指定して満足しない。

### 既刊第1話から守るべき具体的な物と制約
- 2031-11-03午前、市役所の**シャッター内側**に差出人不明の封筒。死亡届の写しは2031-11-04の21:16死亡予定、**死亡者・届出人とも山縣紗月**、受付印がある一方で**四桁の受付番号は削られている**。
- 紗月32歳、図書館資料整理員。自分の「縣」の筆跡の癖を知る人が**本人以外に一人いる**と述べたが名前は未公表。紙には**「三階には上がるな」**の擦れ跡。
- 調査官・佐伯は紗月と11月3日16:05に面会。紗月は旧館三階へ行かないと21:16頃電話で伝え、削られた四桁の元番号を知っていると言った。通話時に鍵の音、誰かが紗月を呼ぶ声。通話は切れ、予告時刻まで24時間となった。
- **解決すべき謎**：誰がどうやって封筒を置いたか／なぜ未来日付なのか／四桁を消した目的／筆跡を知る一人／三階への警告／21:16と鍵の音。数字や鍵を後付けの超常能力で片づけない。法律・役所の実務は調べたものだけ事実扱いし、独自の制度なら架空の設定として整合させる。

### 公開前に作る「1話分の場面設計」
新作は本文を書く前に、編集作業の中で次の4項目を短文で決める。これらは**読者向けのメモ機能ではなく原稿制作側の設計**で、サイトに表示しない。

1. **欲望の衝突**：佐伯は何を明らかにしたいか、紗月は誰／何を守ろうとして何を隠すか。二人の目標を同じにしない。
2. **具体的行動と代償**：登場人物が実際にどこへ行き、どの物を調べ、誰の制止を振り切り、何を失うか。立ち話の説明だけで進めない。
3. **この回で確定する答え**：前話の謎を最低一つ、証拠によって前進させる。「別の謎が出ました」は答えに数えない。
4. **別々の場面の接続**：役所／図書館／日常の一見無関係な物や発言を、後半で同じ原因に結びつける。偶然は出会いのきっかけに使えても、真相を証明する根拠にはしない。

### 第2話執筆前の試作（記録用・正式な正史は連載本文）
- 仮題「消された四桁」。**冒頭**：翌朝、紗月は佐伯を避けるのではなく自ら訪ねる。ただし番号だけを教え、元の死亡届の持ち主を言わない。佐伯は彼女を被害者として守るか、何かに加担した可能性を調べるかで迷う。
- **現場で動く**：佐伯は役所で、受付印・紙の古さ・削り跡が新規作成書類と整合するか確認する。紗月は図書館旧館の記録へ向かう。単なる「不気味な数字の暗号解読」で終わらせない。
- **中盤の反転**：四桁は予言の番号ではなく、**過去に実際に処理された別の届出と結びついていた**、という仮説を実物で確かめる。つまり「未来の書類」ではなく「過去の書類を誰かが加工した」可能性が浮かぶ。誰の死か、なぜ紗月が関係するかは、現実の窓口手続きと既刊の設定に照らして矛盾しない具体的な理由を設計してから決める。
- **人物の選択**：紗月は自身の安全のため三階に行かないと言ったのに、隠していた人物を守るためその約束を破る。その行動を佐伯が目撃し、保護される側だった紗月が**捜査を動かしている人物**にも見える。
- **読後の状態**：「本当に翌日死ぬのか」というだけのサスペンスから、「紗月は過去の誰のために危険を冒すのか」という関係のミステリーに変わる。暗号と意味深な電話の連打は避ける。
- これはプロット案であり**自動的な真相確定・掲載許可ではない**。作中の手続きや人物の動機に無理があれば案を破棄して代案を作る。既刊にない「四年前」「特定の四桁」「真犯人」「実在の役所の制度」を、検証もなく事実として確定しない。

### 第2話で新しく確定する事項（後続回は必ず照合）
- 第2話本文が公開されたら、以下を正史として取り扱う。2026-11-03 は**実際の公開日**、物語内では **2031-11-04 午前8:40〜10時台**。死亡予告の同日 **21:16** は未到来。物語と公開の時間を混同しない。
- 紗月は第1話の21:16の電話を**自分でその時刻まで待ってかけ、意図的に切った**と佐伯に告白。鍵音と呼び声は図書館の夜間閉館作業だった、と紗月が説明した（独立した裏付けはまだない）。佐伯は彼女への信頼を失い、関係が変化した。
- 紗月の母は **山縣美津子**。七年前に死亡し、届出人は紗月。母の死亡届の写しを撮っていた紗月が印刷した写真には、**受付番号6083**、欠けた受付印、斜めの紙筋があった。新しい死亡届と印影・筋・紗月の届出人欄の筆跡が一致し、**死亡者欄だけが美津子から紗月へ変えられていた**。受付印の形を市役所で比較したが、正式な受理記録照会や鑑定の結果はまだない。これを「事件全部の真相確定」と混同しない。
- 母の郷土資料を寄贈した**図書館旧館三階**の箱に家族保管の写しが紛れていたが、紗月が10月末に回収しようとしたときには消えていた。作中の午前10時台、紗月は警告を破って佐伯と三階に上がり、空の袋を見つけた。消えた日付、持ち出した人物、封筒を市役所シャッター内側へ置いた方法は**未解決**。
- 筆跡を知る唯一の人物として紗月が明かしたのは姉の **山縣綾**。姉は母の最期まで病院にいた。紗月は姉を疑いたくなかったが、最後に連絡先を佐伯へ伝え、**身内も捜査から外さない選択**をした。**綾が犯人という証拠はない**。第3話は綾と市役所内側のアクセス手段を事実に基づいて調べる。
- 既出の残る謎（なぜ11/4の21:16か、誰が「三階には上がるな」と書いたか、実際に誰が紙を加工・運んだか）を、読者に新しい脅しの謎だけ加えて先送りしない。さらに新しい事件や人物を入れるなら、既出の状況から因果を作る。

### 脱・定型の編集テスト
本文を一度書いた後、**台詞だけ抜き出して誰の発言か分かるか**、各場面を「誰が／何をしようとして／誰・何に阻まれ／どの行動を選び／何が変わったか」で説明できるか、登場人物の最も痛い選択が描けたかを再確認。読み返しで伏線が**別の意味**を持ち、トリックのHOWと人間のWHYの両方が成立すること。会話のための会話、事件に関係しない奇人変人、説明を盛っただけの伏線は削る。不成立なら次の発行枠を見送って再構成する。

## 未来相場観測室：的中の宣伝より検証
- 速報・ランキング・株価データの大量再配信を狙わず、**仮説→根拠→反証→期限付き判定→振り返り**の一本を深く書く。
- 既出の第1回の明電舎・SWCC・GSユアサ対TOPIXの予測条件・起点日・期日を尊重し、結果が出る前に勝手に変更しない。
- 一次資料（決算短信、決算説明資料、適時開示、官公庁、取引所等）を公開時点で実際に確認し、リンクと確認日を示す。株価・受注・利益率・PER等が取れない場合は**未確認**と書き、数字を補完しない。
- **需要増加≠利益増加≠株価割安**を区別する。銘柄・業種の強気/中立/弱気シナリオと、各シナリオに移る条件を具体化する。
- 最低限、対象・方向または判定条件・比較基準・時間軸・測定方法・反証要因・判定日を事前に記録する。取得できるときは比較の元データと終値も記す。
- 期日到来後の実績で結果を判定し、一次資料などの確認可能な証拠にリンクする。**検証不能は未検証**、結果欄のみ追記してもとの予測は変えない。成績は十分な標本が揃うまで誇張しない。

## 運用と評価
- 自動連載タスクは、GitHub mainの最新版と公開済み全話を確認→新エピソードを追記→テスト/履歴保護→PR→CI成功→main統合→実際の公開URLとrevisionを確認。失敗時は掲載済み扱いにしない。
- 新しい回のテーマタグは[共通の分類手順](ARCHITECTURE.md#テーマタグ)に沿って `content/tags.json` の連載回対応へ登録する。分類だけの変更で既刊の連載JSONを編集しない。
- `scripts/guard_serial_history.py` が過去の小説本文改稿・予測方法の書換え・検証済み結果の後出し変更を防ぐ。正当な訂正が必要な場合は、過去を無言で消さず訂正文や新しい回で説明する。
- 既存の匿名計測から確認できる連載への回遊や再訪は観察するが、**計測されていない読了率・PV・人間の数・投資成績を作らない**。読者の声や実測が増えた場合だけ導線や文量を再評価する。
- 運営追加費は0円固定。API従量課金・GPT追加クレジット・有料GPU/広告/データ取得をしない。文章内容の質が上がらない新機能は後回し。
